# Zwiegespräch Theater Website

Next.js-Website für den Theaterverein Zwiegespräch e.V. (Paderborn).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Deployment

Gehostet auf [Netlify](https://netlify.com). Komplette Anleitung von
Account-Anlage (Resend, PayPal, Netlify) bis zum laufenden Deploy: siehe
[DEPLOYMENT.md](./DEPLOYMENT.md).
